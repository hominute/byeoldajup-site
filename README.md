# 별다줍

‘별걸 다 줍네’의 상품 링크 페이지입니다. 저장소는 `hominute/byeoldajup-site`이며, 이 작업은 **배포 전 구현과 PR 검토**까지 진행합니다. GitHub Pages 설정이나 배포 워크플로는 추가하지 않습니다.

## 로컬 실행

`data/items.json`을 `fetch`로 읽으므로 HTML 파일을 더블클릭하는 대신 HTTP 서버로 열어 주세요.

```bash
python -m http.server 8000
```

저장소 루트에서 실행한 뒤 `http://localhost:8000/`에 접속합니다. 다른 정적 HTTP 서버를 사용해도 됩니다.

## 데이터와 화면의 경계

**상품 목록의 유일한 원본은 `data/items.json`입니다.** 최상위는 상품 객체의 **배열**이며, 필드는 아래 계약을 따릅니다. 상품명·가격·특징·후기·링크 등 개별 상품 데이터를 HTML이나 JavaScript에 중복 작성하지 않습니다.

| 필드 | 형식·용도 |
|---|---|
| `no` | 문자열 상품 번호. `001`처럼 앞의 0을 유지 |
| `category` | 분류 이름. 화면에서 동적으로 목록 구성 |
| `name` | 실제 상품 이름 |
| `hook` | JSON에 정한 짧은 소개 문구 |
| `facts` | 확인된 특징을 담은 문자열 배열 |
| `proof` | JSON에 기록한 근거·확인 자료 문구 |
| `checkedAt` | 자료 확인일. `YYYY-MM-DD` 형식 |
| `image` | 상품 이미지 경로 |
| `url` | 실제 판매처·제휴 링크 |

`proof`는 `checkedAt` 시점의 자료이며 실시간 구매 수·평점 연동이 아닙니다. 값을 임의로 갱신하거나 확인일 없이 현재 수치로 소개하지 않습니다.

| 담당 | 수정 범위 |
|---|---|
| GPT | `index.html`, 테마 스타일, 화면용 이미지·캐릭터, JavaScript, 검수 증빙 |
| Claude | `data/items.json`, `assets/items/`의 실제 상품 이미지 |

화면은 JSON에서 분류를 구성하고 검색·랜덤 상품 선택·상품 해시 링크를 처리합니다. 새 상품을 추가할 때 개별 상품용 화면 코드를 추가하는 구조로 만들지 않습니다. JSON에 없는 기능·성능·가격·후기·인증을 화면 문구로 만들어 넣지 않습니다.

상품 찜·즐겨찾기·링크 보관함 기능은 없습니다. 브라우저에는 방문자가 선택한 **테마 취향만** 기억합니다. 저장 공간을 쓸 수 없거나 설정이 올바르지 않으면 별도 오류 안내 없이 A 테마로 표시합니다. 상품 목록은 JSON 파일에 있으므로 브라우저 기록을 지워도 없어지지 않습니다.

## 다섯 테마와 이미지

A~E의 서로 다른 디자인을 제공합니다. 테마 배경과 투명 캐릭터는 각각 분리된 자산으로 사용합니다. 전체 페이지 시안을 잘라 배경·캐릭터처럼 보여주는 방식은 사용하지 않습니다.

현재 시드 상품의 실제 이미지가 제공되지 않은 경우에는 **상품 사진이 아닌 준비 중 표시용 그래픽**을 보여줍니다. 이를 실제 제품 사진으로 소개하지 않습니다. Claude가 `assets/items/001.webp` 등 실제 상품 이미지를 제공하고 JSON에 해당 경로를 반영해야 합니다.

## 고지와 링크

정식 쿠팡파트너스 대가성 고지는 페이지 맨 위에 고정하고, 하단에는 상품 정보의 출처·변동 가능성·직접 사용 후기가 아니라는 안내를 유지합니다. 고지를 장식·호버·접힌 영역 안에 숨기지 않습니다. 실제 판매처와 본인 계정에서 발급한 제휴 링크를 JSON에 연결하고, 연결 전에는 임의의 타인 제휴 링크를 넣지 않습니다.

## 변경과 검수

- GPT 디자인 작업은 `gpt/design-themes` 브랜치에서 진행하고 PR로 검토합니다.
- 새 저장소의 최초 구조를 만드는 부트스트랩을 제외하고 `main`을 직접 수정하지 않습니다.
- 상품 데이터와 실제 상품 이미지는 Claude 담당 범위를 보존합니다.
- JSON에 두 번째 항목을 추가한 테스트로 동적 분류·검색·랜덤 선택·해시 연결을 확인합니다.
- 360px와 430px 모바일 화면에서 다섯 테마, 버튼, 글자와 이미지의 잘림을 확인합니다.
- 브라우저 저장소를 사용할 수 없는 상태에서도 상품 목록이 열리고 A 테마가 표시되는지 확인합니다.

모바일 화면 증빙은 검수 후 아래 경로에 둡니다. 파일이 존재하거나 실제 검수가 끝나기 전에는 통과했다고 기록하지 않습니다.

```text
docs/screenshots/a-mobile.jpg
docs/screenshots/b-mobile.jpg
docs/screenshots/c-mobile.jpg
docs/screenshots/d-mobile.jpg
docs/screenshots/e-mobile.jpg
```

협업 규칙은 `CONTRIBUTING.md`를 확인하세요.

## 검수와 전달 상태

`node tests/app.test.cjs`로 10개 검사를 실행합니다. 실제 완료 결과는 `docs/QA.md`에 기록했습니다. PR에 사용할 설명은 `PR_BODY.md`, Claude 인계 요청은 `docs/HANDOFF-ISSUE.md`에 있습니다. 이 파일들은 PR·Issue 작성용 원고이며, 실제 원격 등록 결과는 인계 기록에서 확인합니다.

이전 원본 시안 5장은 `docs/references/`에 보존했습니다. 현재 화면의 배경·캐릭터에는 이 시안을 사용하지 않습니다. 새 자산의 프롬프트와 제작 기록은 각 `assets/themes/*/ASSET-NOTES.md`를 확인하세요.
