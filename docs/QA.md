- A~E 전부 360px·430px에서 `scrollWidth === clientWidth`였습니다. 390px 캡처 5장은 `docs/screenshots/`에 있습니다.

- 배경 WebP와 투명 캐릭터 PNG 10개는 새로 각각 생성했습니다. 캐릭터 5개 모두 실제 알파 채널을 확인했습니다. 생성 프롬프트는 테마별 ASSET-NOTES에 있습니다.

## 남아 있는 범위

- 실제 인스타그램·유튜브 앱 안의 브라우저와 iOS/Android 실기기는 사용하지 않았습니다. 현재 캡처는 Chromium의 동일한 모바일 폭을 사용한 검수입니다.
- 상품명·확인 정보·상품평 수·구매 수·확인 날짜·제휴 링크는 사용자가 제공한 JSON 시드입니다. 이 작업에서 판매 페이지를 다시 조사하거나 직접 사용한 것으로 표현하지 않았습니다.
- 실제 `assets/items/001.webp`는 아직 제공되지 않았고, 화면에는 ‘상품 이미지 준비 중’ 표시가 나옵니다. Claude가 실제 상품 이미지를 추가해야 합니다.
- 공개 저장소 `hominute/byeoldajup-site`를 생성했습니다. 구현 변경은 `gpt/design-themes` 브랜치에서 검토하며, `main`에는 초기 README만 두고 PR 병합 전까지 유지합니다. PR·Issue 등록 링크는 별도 인계 기록에서 확인합니다.
- GitHub Pages, 배포 워크플로, 외부 추적 스크립트, 분석 도구는 추가하지 않았습니다.
